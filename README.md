# 8 Mini Browsers

Android-приложение с 8 окнами WebView, расположенными сеткой 2×4 (2 колонки, 4 ряда).
В каждом окне можно вписать/заменить свою ссылку и открыть её кнопкой **Go**.
У каждого окна есть кнопки «назад», «вперёд», «обновить» и кнопка **⛶** —
разворачивает это окно на весь экран; кнопка **🗗** в развёрнутом режиме
сворачивает окно обратно на исходное место в сетке.

## Как собрать APK на GitHub Actions

1. Создай новый репозиторий на GitHub (публичный или приватный).
2. Загрузи в него всё содержимое этой папки, сохранив структуру:
   ```
   MiniBrowser8/
   ├── app/
   │   ├── build.gradle.kts
   │   └── src/main/...
   ├── .github/workflows/build-apk.yml
   ├── build.gradle.kts
   ├── settings.gradle.kts
   └── gradle.properties
   ```
   Проще всего: открой репозиторий на GitHub в браузере →
   **Add file → Upload files** → перетащи все файлы и папки → **Commit changes**.
3. Перейди во вкладку **Actions** репозитория. Workflow «Build APK» запустится
   автоматически после коммита (или нажми **Run workflow**, если видишь
   кнопку запуска вручную).
4. Дождись зелёной галочки (сборка занимает пару минут).
5. Открой завершённый запуск → внизу страницы, в разделе **Artifacts**,
   будет файл `MiniBrowser8-debug-apk` — скачай его, внутри `app-debug.apk`.
6. Перенеси APK на планшет/телефон и установи (потребуется разрешить
   установку из неизвестных источников).

## Заметки

- Собирается debug-сборка (не нужен ключ подписи, чтобы всё было просто).
- Ссылки по умолчанию пустые — впиши нужный адрес в поле каждого окна и
  нажми **Go** (или Enter).
- Экран приложения зафиксирован в альбомной ориентации.
